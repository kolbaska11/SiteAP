## Как посмотреть

В браузере доступна **отдельная публичная демонстрация клиентской части**. Можно переключать вкладки, открывать карточки заказов, рассчитывать стоимость, создавать примерные заявки, отправлять сообщения внутри демо и открывать ответы на вопросы.

> **Демонстрационный режим:** все заказы, переписка и личные данные на странице — примеры. Действия работают локально в браузере; файлы и сообщения не передаются в типографию. Это презентация клиентского интерфейса, а не рабочий кабинет с авторизацией.

## Административная панель

В состав веб-приложения также входит отдельная **панель управления типографией**: обработка заказов и клиентской базы, статусы производства, переписка, справочная информация, цены, рекламные материалы и настройки.

Административный интерфейс и серверные компоненты **не входят в публичную демонстрацию**.

## Локальный запуск

Публичную демоверсию можно посмотреть без Node.js и сервера.

1. Скачать репозиторий.
2. Открыть файл **\`docs/index.html\`** в браузере.
3. Переключаться между разделами и проверять интерфейс.

Все файлы публичной демонстрации находятся в **\`docs/\`**. Для публикации на GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch → ветка `main`, каталог `/docs` → Save**.
